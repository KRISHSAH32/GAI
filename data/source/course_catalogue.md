# University Course Catalogue (2026-2027)

## Computer Science & Data Science Courses

### CS101: Introduction to Computer Science
- **Credits**: 4
- **Description**: Fundamental concepts of computation, problem-solving, algorithms, and computing systems.
- **Prerequisites**: None
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### CS102: Programming in Python
- **Credits**: 4
- **Description**: Procedural and object-oriented programming using Python, data structures, control flows, and file I/O.
- **Prerequisites**: CS101
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### MATH101: Linear Algebra & Calculus
- **Credits**: 4
- **Description**: Matrices, vector spaces, eigenvalues, multivariable calculus, and optimization foundations.
- **Prerequisites**: None
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### MATH201: Probability & Statistics
- **Credits**: 4
- **Description**: Discrete and continuous probability distributions, estimation, hypothesis testing, and regression analysis.
- **Prerequisites**: MATH101
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### CS201: Data Structures & Algorithms
- **Credits**: 4
- **Description**: Arrays, linked lists, stacks, queues, trees, graphs, sorting, searching, and algorithmic complexity analysis.
- **Prerequisites**: CS102
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### CS202: Database Management Systems
- **Credits**: 4
- **Description**: Relational data models, SQL, normalization, indexing, transaction processing, and NoSQL databases.
- **Prerequisites**: CS102
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### CS301: Advanced Algorithms & Design
- **Credits**: 4
- **Description**: Greedy algorithms, dynamic programming, NP-completeness, graph algorithms, and approximation strategies.
- **Prerequisites**: CS201
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### DS101: Foundations of Data Science
- **Credits**: 4
- **Description**: Data collection, exploratory data analysis, data wrangling, and basic machine learning workflows.
- **Prerequisites**: CS102
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### DS201: Data Visualization & Communication
- **Credits**: 3
- **Description**: Visual design principles, Matplotlib, Seaborn, Tableau, and storytelling with data.
- **Prerequisites**: DS101
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### DS301: Data Mining & Knowledge Discovery
- **Credits**: 4
- **Description**: Association rule mining, clustering, anomaly detection, text mining, and big data architectures.
- **Prerequisites**: CS201, MATH201
- **Corequisites**: DS301L (Data Mining Lab)
- **Offering**: Spring 2027

### DS301L: Data Mining Lab
- **Credits**: 1
- **Description**: Hands-on practical lab for DS301 using PySpark and Scikit-Learn.
- **Prerequisites**: CS201
- **Corequisites**: DS301
- **Offering**: Spring 2027

### AI301: Artificial Intelligence Principles
- **Credits**: 4
- **Description**: Search algorithms, knowledge representation, logic, probabilistic reasoning, and search games.
- **Prerequisites**: CS201, MATH201
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

### AI401: Advanced Machine Learning & Deep Learning
- **Credits**: 4
- **Description**: Supervised/unsupervised learning, neural networks, CNNs, RNNs, Transformers, and optimization algorithms.
- **Prerequisites**: CS201 AND MATH201 (Must have passed both with grade C or higher)
- **Corequisites**: None
- **Offering**: Spring 2027

### CS305: Deep Learning Systems & Hardware Acceleration
- **Credits**: 4
- **Description**: GPU programming, CUDA, Distributed Training, Quantization, and LLM serving architectures.
- **Prerequisites**: AI301
- **Corequisites**: None
- **Offering**: Fall 2026 ONLY (NOT offered in Spring 2027 or Summer 2027)

### DS405: Quantum Computing for Data Science
- **Credits**: 4
- **Description**: Qubits, quantum logic gates, Grover/Shor algorithms, and quantum machine learning.
- **Prerequisites**: MATH201 AND Special Permission from Department Head
- **Corequisites**: None
- **Offering**: Spring 2027

### DS490: Senior Data Science Capstone Project
- **Credits**: 6
- **Description**: Year-long industry or research project applying full data science lifecycle.
- **Prerequisites**: Minimum 100 completed credits, AI301, and CS202
- **Corequisites**: None
- **Offering**: Fall 2026, Spring 2027

- **Offering**: Fall 2026, Spring 2027

### FIN101: Corporate Finance & Financial Analytics
- **Credits**: 3
- **Description**: Capital budgeting, valuation models, risk metrics, and financial modeling.
- **Prerequisites**: MATH101
- **Offering**: Fall 2026, Spring 2027
